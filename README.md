# RootifyONE

Administração central da plataforma **SolverONE** — `https://solverone.com.br/rootify-one/`.

HTML, CSS e JavaScript puros, sem build. Os dados ficam cifrados no navegador de quem usa.

- **Leia antes de mexer:** [`ARQUITETURA.md`](ARQUITETURA.md)
- **Como publicar e configurar (passo a passo, para iniciantes):** [`PASSO-A-PASSO-ROOTIFY-ONE.md`](PASSO-A-PASSO-ROOTIFY-ONE.md)
- **Testar no computador:** `node servidor-teste.js` e abra `http://localhost:8098`
- **O que cada versão trouxe:** `versoes.json` (e ⚙ → Sobre, dentro do app)
